# Changelog

## [1.0.0] - 2026-11-23

### Added
- Data loading, validation and cleaning for the IBM Telco Customer Churn dataset
- EDA script producing figures and a data-driven report
- Feature engineering and scikit-learn preprocessing pipeline
- Comparison of Logistic Regression, Random Forest and Gradient Boosting with 5-fold cross-validation
- One-standard-deviation model selection rule
- Cost-based decision threshold selection
- Evaluation plots and permutation importance
- Streamlit dashboard: overview, single prediction, batch scoring, model performance
- Grouped what-if explanations for single predictions
- 43 automated tests, Ruff linting, GitHub Actions workflow
- Dockerfile and Docker Compose configuration (not built in the development environment)
- Documentation set
