# Dataset

`Telco-Customer-Churn.csv` is the IBM Telco Customer Churn sample dataset (7,043 customers, 21 columns).

- Source: https://github.com/IBM/telco-customer-churn-on-icp4d
- License: Apache License 2.0 (copy in `LICENSE-IBM-APACHE-2.0.txt`)
- Contains no personal data; `customerID` values are anonymous sample identifiers.
- Re-download with `python scripts/download_data.py`.
